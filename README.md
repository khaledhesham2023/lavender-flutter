# lavender_flutter

A cross-platform mobile application built with Flutter designed to bridge the gap between patients and healthcare providers. The app enables users to seamlessly discover doctors, schedule and manage appointments, and unlock exclusive discounts on specialized medical treatment sessions and promotional wellness packages.
